# Сайт УК «МИРА»: инструкция для разработчика

Статический сайт из одной страницы. Сборка, сервер и база данных не нужны: папку можно выкладывать как есть.

## Структура

```
index.html               страница
assets/css/style.css     стили
assets/js/main.js        скрипты (без библиотек)
assets/img/              логотип, фото объектов (neimark-*, ufa-*), обложки видео
assets/video/hero.mp4               фоновое видео первого экрана
assets/video/miraverse-trailer.mp4  превью в блоке «Цифровые сервисы»
assets/video/miraverse.mp4          полный ролик (открывается по кнопке «Смотреть полностью»)
```

## Как выложить

1. Скопировать содержимое папки в корень сайта (рядом с `index.html` должна лежать папка `assets`).
2. Включить HTTPS.
3. Проверить, что сервер отдаёт `.mp4` с типом `video/mp4` и поддерживает Range-запросы (nginx и Apache делают это по умолчанию).
4. Желательно включить gzip или brotli для html, css, js и задать долгий кэш для `assets/`.

Пример для nginx:

```nginx
location /assets/ { expires 30d; add_header Cache-Control "public"; }
gzip on; gzip_types text/css application/javascript;
```

## Что нужно доделать на стороне сайта

- **Форма «Расскажите о своём проекте».** Сейчас она никуда не отправляет данные, а только показывает «Спасибо…». Её нужно подключить к почте или CRM: обработчик находится в `assets/js/main.js`, ищите комментарий `/* форма */`. Поля формы: `name`, `org`, `contact`, `about`.
- **Шрифты** (Unbounded, Golos Text) загружаются с Google Fonts. Если нужна независимость от внешних сервисов, их можно скачать и подключить локально.
- **Favicon и превью для соцсетей** (og:image) пока не заданы.
- **Аналитика** (Яндекс Метрика и т. п.) не подключена.

## Проверено

Chrome, desktop 1440px. Видео на первом экране, превью при наведении, полный ролик, окна «Узнать больше», галереи объектов. Ошибок в консоли нет.
